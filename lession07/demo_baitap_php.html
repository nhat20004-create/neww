Bài 1: Tính tổng tiền đơn hàng

Biến · Phép tính

Viết chương trình PHP tính tổng tiền một đơn hàng.

Dữ liệu cho trước

Tên sản phẩm"Bánh mì"
Đơn giá15000
Số lượng3

Yêu cầu

  1. Khai báo các biến tương ứng.
  2. Tính thành tiền.
  3. Tính VAT 10%.
  4. Tính tổng tiền phải trả.
  5. In kết quả ra màn hình / terminal / console.

Bài 2: Đánh giá kết quả học viên

if / elseif / else

Dữ liệu cho trước

$name = "Nguyen Van An";

Bài 3: Danh sách sản phẩm

Mảng · foreach · Điều kiện

Cho danh sách sản phẩm:

$products = [
    [
        "name" => "Bánh mì",
        "price" => 15000,
        "quantity" => 2
    ],
    [
        "name" => "Sữa",
        "price" => 30000,
        "quantity" => 1
    ],
    [
        "name" => "Trứng",
        "price" => 25000,
        "quantity" => 3
    ]
];

Yêu cầu

  1. Duyệt qua danh sách sản phẩm bằng foreach.
  2. In tên, đơn giá và số lượng của từng sản phẩm.
  3. Tính thành tiền của từng sản phẩm: thành tiền = price × quantity
  4. Tính tổng tiền của toàn bộ đơn hàng.
  5. Nếu tổng tiền >= 100000 thì giảm giá 10%.
  6. Nếu tổng tiền < 100000 thì không giảm giá.
  7. In ra kết quả theo mẫu bên dưới.

Kết quả mong đợi

Output

===== DANH SÁCH SẢN PHẨM =====

Bánh mì - 15,000 VNĐ x 2 = 30,000 VNĐ
Sữa - 30,000 VNĐ x 1 = 30,000 VNĐ
Trứng - 25,000 VNĐ x 3 = 75,000 VNĐ

Tạm tính: 135,000 VNĐ
Giảm giá: 13,500 VNĐ
Thanh toán: 121,500 VNĐ

Bài 4 (Thực hành 7-4): Chia file PHP thành các function con

function · tham số · return

Viết lại chương trình của Bài 3: tách code thành các function con, mỗi function làm một việc. Giữ nguyên dữ liệu $products và kết quả in ra.

Yêu cầu

  1. Giữ nguyên mảng $products như Bài 3.
  2. Viết tối thiểu các function sau:
    formatMoney($amount)Trả về chuỗi tiền đã định dạng, ví dụ 15000 → "15,000 VNĐ"
    calculateLineTotal($product)Trả về thành tiền của 1 sản phẩm (price × quantity)
    calculateSubtotal($products)Trả về tổng tiền của toàn bộ đơn hàng
    calculateDiscount($subtotal)Trả về số tiền giảm: 10% nếu >= 100000, ngược lại trả về 0
    printProductList($products)In tiêu đề và từng dòng sản phẩm
    printSummary($products)In Tạm tính, Giảm giá, Thanh toán
  3. Các function tính toán (calculate…, formatMoney) phải dùng return để trả kết quả, không được echo bên trong.
  4. Không dùng biến toàn cục (global) — dữ liệu truyền vào qua tham số.
  5. Function in kết quả phải gọi lại các function tính toán, không tính lại bằng code lặp.
  6. Phần chương trình chính chỉ gồm khai báo $products và gọi 2 function in: 
    printProductList($products);
printSummary($products);

  • Tách các function sang file functions.php, file chính index.php dùng require_once 'functions.php'; để gọi.
  • Đổi quantity của "Trứng" thành 1 rồi chạy lại: tổng còn 85,000 VNĐ (dưới 100,000), nên dòng Giảm giá phải là 0 VNĐ.
