Hướng dẫn cài Composer trên Windows đã có XAMPP

Nếu máy tính đã cài XAMPP, bạn có thể cài Composer và sử dụng PHP của XAMPP để quản lý thư viện cho các dự án PHP như Laravel, CakePHP hoặc các project PHP khác.

Cách dễ nhất là sử dụng trình cài đặt Composer-Setup.exe.

Bước 1: Kiểm tra PHP của XAMPP

  1. Mở thư mục XAMPP, thường là C:\xampp.
  2. Kiểm tra file PHP tại đường dẫn C:\xampp\php\php.exe.
  3. Mở Command Prompt (CMD) hoặc PowerShell.
  4. Chạy lệnh sau để kiểm tra PHP:
C:\xampp\php\php.exe -v

Nếu hiển thị thông tin phiên bản PHP, nghĩa là PHP của XAMPP đang hoạt động.

Nếu XAMPP được cài ở thư mục khác, hãy thay C:\xampp bằng đường dẫn thực tế.

Bước 2: Tải Composer

Tải trình cài đặt Composer từ trang chính thức:

Tải Composer-Setup.exe

  1. Chạy file Composer-Setup.exe.
  2. Nếu trình cài đặt yêu cầu chọn PHP, hãy chọn Browse.
  3. Chọn file PHP của XAMPP: C:\xampp\php\php.exe.
  4. Tiếp tục theo hướng dẫn của trình cài đặt.
  5. Hoàn tất quá trình cài đặt.
Nếu trình cài đặt phát hiện thiếu extension hoặc cấu hình PHP, hãy đọc thông báo và xử lý trước khi tiếp tục.

Bước 3: Kiểm tra Composer đã cài thành công

  1. Đóng CMD hoặc PowerShell đang mở.
  2. Mở một cửa sổ CMD mới.
  3. Chạy lệnh sau:
composer -V

Kết quả sẽ tương tự:

Composer version 2.x.x
Nếu hiển thị phiên bản Composer, nghĩa là Composer đã được cài đặt thành công.

Kiểm tra PHP mà Windows đang sử dụng:

php -v

Nếu lệnh php không chạy hoặc báo không nhận diện được, có thể PHP của XAMPP chưa được thêm vào PATH.

Bước 4: Thêm PHP của XAMPP vào PATH nếu cần

Nếu muốn gọi lệnh php từ bất kỳ thư mục nào trong CMD, hãy thực hiện:

  1. Nhấn phím Windows và tìm Edit the system environment variables.
  2. Chọn Environment Variables.
  3. Trong phần User variables hoặc System variables, chọn Path rồi nhấn Edit.
  4. Chọn New và thêm đường dẫn:
C:\xampp\php
  1. Nhấn OK để lưu các thay đổi.
  2. Đóng CMD và mở lại.

Kiểm tra bằng các lệnh:

php -v
composer -V
where php
where composer

Lệnh where php nên hiển thị PHP nằm trong thư mục XAMPP nếu bạn muốn sử dụng PHP của XAMPP.

Bước 5: Thử Composer trong project PHP

Ví dụ, project của bạn nằm tại: 

C:\xampp\htdocs\myproject

Mở CMD và chạy:

cd C:\xampp\htdocs\myproject
composer init

Composer sẽ hướng dẫn bạn tạo file composer.json.

Nếu project đã có file composer.json, chỉ cần chạy: 

composer install

Lệnh này cài đặt các thư viện được khai báo trong project vào thư mục vendor.

Lưu ý

  • Cài Composer không đồng nghĩa với việc phải khởi động Apache hoặc MySQL trong XAMPP.
  • Composer chạy trực tiếp qua PHP CLI của XAMPP.
  • Nên kiểm tra phiên bản PHP mà project yêu cầu trước khi cài các thư viện.
